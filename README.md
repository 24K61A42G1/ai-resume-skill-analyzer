# AI-Based Resume Skill Analyzer

## 📌 Project Overview
This project is an AI-based application that analyzes resumes, extracts technical skills, matches them with predefined job roles, and identifies missing skills using Natural Language Processing (NLP) techniques.

## 🚀 Features
- Resume text preprocessing using NLP
- Skill extraction from resumes
- Job role-based skill matching
- Skill gap analysis
- AI similarity scoring using TF-IDF and Cosine Similarity
- Smart job readiness recommendation

## 🛠 Technologies Used
- Python
- Natural Language Processing (NLP)
- Scikit-learn
- TF-IDF
- Cosine Similarity
